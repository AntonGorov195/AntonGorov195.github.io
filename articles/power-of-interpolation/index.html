The Power of Interpolation

This article exploreres the concept of interpolation and how I used it for my sorting animation project.

Author: Anton Gorov
Date: 22/1/2026
Last Update: 22/1/2026

You can represent animation by a starting value, end value, duration, and an interpolation function. Then given a value "t" which represents a time from the start of the animation, you can get the current value. This can be used in other places than just animation. Anything that has an upper bound and lower bound. The "t" also doesn't have to be time.
